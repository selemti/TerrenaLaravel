# Terrena Documentation Index

Esta guía resume las carpetas principales dentro de `docs/` para que puedas ubicar rápidamente la documentación según módulo o flujo.

## Carpetas por módulo o función

- **CajaChica**: Lifecycle, wizard de cortes, permisos y todo el paquete `FondoCaja/` con arquitectura, migraciones y componentes Livewire.
- **Ventas**: Análisis de discrepancias, scripts de investigación, resultados históricos y el submódulo `Descuentos & Void/`.
- **Reports**: Correcciones de layout, catálogos de dashboards y guías de reportería (`README_REPORTES_ERP_V10.md`, `JASPER_EQUIVALENTS.md`).
- **Migraciones**: Estado y verificación de lotes ejecutados (`ANALISIS_MIGRACIONES_*`, `MIGRACIONES_*`).
- **Planeacion**: Planes de ataque, roadmap, sesiones completadas, resúmenes de sprint y revisiones de entrega.
- **Arquitectura**: Libro técnico, convenciones, rutas/controladores y análisis CRUD a nivel plataforma.
- **BD**: Diccionarios de datos, ERDs, auditorías y scripts utilitarios bajo `BD/scripts/`.
- **Inventario**: Flujos de alta, políticas UOM, API, y archivo histórico en `Inventario/legacy/`.
- **Seguridad**: Políticas de auditoría, caching de auth, roles y matrices de permisos.
- **Onboarding**: Contexto del proyecto, guía de setup y tips rápidos para exportar documentación.
- **Orquestador**: Evidencias del daily close y sesiones exportadas en `Orquestador/evidencia/sesiones/`.
- **Otros módulos**: Directorios existentes para Front, POS, Purchasing, Produccion, Replenishment, Recetas, InventoryCounts, PosConsumption, UI-UX, V2 y V3 se mantienen sin cambios y conservan su documentación especializada.

## Archivos históricos y respaldo

- `docs/_archive/` contiene entregables empaquetados como `docs_27_10_2025.zip`.

Si agregas nuevas carpetas o mueves archivos, actualiza este índice para mantener la trazabilidad del repositorio de documentación.
