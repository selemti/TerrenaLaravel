================================================================================
TABLA TRANSACCIONAL: MOVIMIENTOS INVENTARIO (mov_inv)
================================================================================

Es el KARDEX/JOURNAL de toda operación de inventario.

Estructura:
- id (bigint): autoincrementado (seq: mov_inv_id_seq)
- ts (timestamp): timestamp del movimiento (CRITICAL for queries)
- item_id (varchar): FK a items
- lote_id (integer): FK a lote (batch)
- cantidad (numeric): cantidad en UOM base
- qty_original (numeric): cantidad en UOM original
- uom_original_id (integer): FK unidad origen
- costo_unit (numeric): costo unitario del movimiento
- tipo (varchar): ENTRADA, SALIDA, AJUSTE, etc.
- ref_tipo (varchar): RECEPCION, TRANSFER, CONSUMO, etc.
- ref_id (bigint): ID de la referencia (receipt ID, transfer ID, etc.)
- sucursal_id (varchar): sucursal donde ocurrió

Índices Estratégicos:
- (item_id, ts): buscar movimientos de un item por período
- (tipo, ts): buscar movimientos por tipo en período
- (ts, tipo): ordenar por timestamp con filtro
- (ref_tipo, ref_id): reconciliación de referencias

NOTA: Esta tabla es CRÍTICA para toda la auditoría de inventario.
Una sola entrada errónea puede afectar balances.

CONSULTAS FRECUENTES Y SU OPTIMIZACIÓN
================================================================================

1. "¿Cuál es el stock actual de un item?"
   SELECT SUM(cantidad) FROM selemti.mov_inv WHERE item_id = ?
   ÍNDICE USADO: idx_mov_inv_item_id

2. "¿Qué movimientos tuvimos en este período?"
   SELECT * FROM selemti.mov_inv WHERE ts >= ? AND ts < ?
   ÍNDICE USADO: idx_mov_inv_ts

3. "¿Qué entradas tuvimos de un item?"
   SELECT * FROM selemti.mov_inv WHERE item_id = ? AND tipo = 'ENTRADA'
   ÍNDICE USADO: (item_id, ts) o (tipo, ts)

4. "¿Cuáles son los items con bajo stock?"
   SELECT i.*, COALESCE(SUM(m.cantidad), 0) as stock
   FROM selemti.items i
   LEFT JOIN selemti.mov_inv m ON i.id = m.item_id
   LEFT JOIN selemti.stock_policy sp ON i.id = sp.item_id
   WHERE COALESCE(SUM(m.cantidad), 0) < sp.min_qty
   ÍNDICE USADO: idx_items_activo + idx_mov_inv_item_id

5. "¿Qué lotes están próximos a vencer?"
   SELECT * FROM selemti.lote
   WHERE caducidad <= CURRENT_DATE + INTERVAL '30 days'
   ÍNDICE USADO: ix_lote_cad
